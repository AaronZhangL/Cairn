# LLM Space Firecrawl web tools

Checked on 2026-09-24 against `deer-flow/llm-space` commit [`e65eea24c87ee5b91618b7eb50e2af77a30ef042`](https://github.com/deer-flow/llm-space/tree/e65eea24c87ee5b91618b7eb50e2af77a30ef042). This is about **LLM Space**, not the separate `bytedance/deer-flow` project.

## Answer

Yes. LLM Space defaults to Firecrawl and its current runtime sends `web_search` and `web_fetch` requests **without an `Authorization` header when no `FIRECRAWL_API_KEY` is available**. It uses hosted `https://api.firecrawl.dev/v2/search` and `/v2/scrape`, respectively. An API key is optional for the keyless tier, not required to make the request. See the [default settings](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/core/src/types/search.ts#L30-L38) and [runtime implementation](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/runtime/src/tools/built-in/web.ts#L127-L205). Firecrawl's [official search guide](https://docs.firecrawl.dev/features/search) also shows a keyless REST request.

This is a hosted third-party service, not local search or a bundled search index. LLM Space's base URL is hard-coded to Firecrawl Cloud; its settings expose a key but no self-hosted Firecrawl URL. [Runtime source](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/runtime/src/tools/built-in/web.ts#L10-L16), [search settings type](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/core/src/types/search.ts#L20-L38). Firecrawl itself offers [self-hosting](https://github.com/firecrawl/firecrawl/blob/main/SELF_HOST.md), but that is a separate multi-service deployment, not a prerequisite or part of LLM Space's implementation.

## Limits, cost, and failure path

- Firecrawl's current [rate-limit documentation](https://docs.firecrawl.dev/rate-limits) says keyless REST Search and Scrape are free but capped by **both requests and credits per IP per day**; it does not state the numeric daily caps there. Exceeding either returns `429`. A registered free API key has higher limits and 1,000 credits. Its [billing documentation](https://docs.firecrawl.dev/billing) explicitly distinguishes keyless daily IP limits from the account-based free plan's monthly allotment.
- The [billing table](https://docs.firecrawl.dev/billing) lists search at 2 credits per 10 results and basic scrape at 1 credit per page; scraped search results incur additional per-page scrape costs. LLM Space always sends `scrapeOptions` asking for markdown on search results, so its searches can cost more credits than a link-only search. [LLM Space request body](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/runtime/src/tools/built-in/web.ts#L174-L206).
- LLM Space does not silently switch from Firecrawl to another provider when this tier is exhausted. It propagates the Firecrawl error and has a [specific daily-limit dialog](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/apps/desktop/src/i18n/playground-labels.ts#L51-L56) asking the user to configure a key. Its [provider selection](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/runtime/src/tools/built-in/web.ts#L840-L919) is explicit, not an automatic fallback chain. Other named providers include Tavily, Brave, Exa, AnySearch, and Zhihu; some `web_fetch` paths still delegate to Firecrawl.

## Documentation drift and verification boundary

The pinned LLM Space [Settings manual](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/docs/settings.md#L202-L230) still says Firecrawl "Requires a Firecrawl API Key" and lists only Firecrawl and Tavily. Both statements are outdated relative to the same commit's [runtime](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/runtime/src/tools/built-in/web.ts#L840-L919) and [settings type](https://github.com/deer-flow/llm-space/blob/e65eea24c87ee5b91618b7eb50e2af77a30ef042/packages/core/src/types/search.ts#L1-L38). Firecrawl's [June 2026 keyless launch post](https://www.firecrawl.dev/blog/firecrawl-keyless-launch) advertises 1,000 free credits/month without signup, but its current [rate-limit](https://docs.firecrawl.dev/rate-limits) and [billing](https://docs.firecrawl.dev/billing) pages describe anonymous access as a separate per-IP, per-day capped tier. Use the latter for current limit expectations.

No live anonymous API query was sent in this investigation; the conclusion is supported by the pinned code and Firecrawl's official API documentation, not a local success test.

## Implication for Cairn

Firecrawl is a plausible keyless HTTP search-and-fetch backend for a lightweight desktop companion, with no Python dependency or self-hosted service. It would send the model's query and any fetched URL to Firecrawl Cloud; its anonymous quota is finite and shared by IP. This is an **alternative product choice**, not evidence that Cairn must replace its current provider. If considered for implementation, the search request should be scoped to the answer's actual needs: LLM Space's always-on search-result scraping trades denser evidence for extra credit use, while Cairn already has a separate fetch tool.
